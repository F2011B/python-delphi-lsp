# Python Delphi LSP 2.3 Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make multi-million-line workspaces faster to open, prewarm, query, update, and reopen while retaining deterministic Protocol v2 results and bounded memory.

**Architecture:** Store one current workspace revision, preprocess ordinary text in spans, persist compact content-addressed navigation shards, and derive indexed/lazy query results from those shards. Metrics and relations gain bounded parallel extraction stages followed by deterministic parent-process aggregation.

**Tech Stack:** Python 3.10–3.14, `pathlib`, `hashlib`, atomic JSON shard files, `ProcessPoolExecutor`, watchfiles, pytest, cProfile, existing FPC performance corpus.

class AgentWorkspace:

- [ ] **Step 3: Add `append_span()` and scan ordinary runs**

`_OutputBuffer` stores text chunks and line-map entries. Implement:

```python
def append_span(
    self,
    text: str,
    file_name: str,
    line: int,
    *,
    active: bool,
) -> None:
    emitted = text if active else _blank_preserving_newlines(text)
    self._chunks.append(emitted)
    for offset, character in enumerate(emitted):
        if offset == 0 or emitted[offset - 1] == "\n":
            self._line_map.append(SourceMapEntry(file_name, line, 0))
        if character == "\n":
            line += 1
```

The main loop finds the next special delimiter (`'`, `//`, `{`, `(*`) and
emits the intervening run once. Preserve the existing directive and include
logic.
